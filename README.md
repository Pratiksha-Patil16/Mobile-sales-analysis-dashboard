# 📊 Sales Data Analysis Dashboard (Power BI)

## 📌 Project Overview
This project is a Sales Data Analysis Dashboard built using Power BI.  
It analyzes mobile sales data to generate insights about sales performance, customer behavior, and product trends.

The goal is to transform raw sales data into meaningful visual insights for better business decision-making.

---

## 📂 Dataset Information
The dataset includes the following columns:

- Transaction ID  
- Date  
- Day Name  
- Brand  
- Unit Sold  
- Price per Unit  
- Customer Name  
- Customer Age  
- City  
- Payment Method  
- Customer Ratings  
- Mobile Model  

---

## 🛠 Tools Used
- Power BI  
- Power Query  
- Data Visualization Techniques  

---

## 📊 Key Analysis Performed

### 1. Sales Analysis
- Total Sales by City  
- Total Sales by Month  
- Total Sales by Day Name  

### 2. Product Analysis
- Total Sales by Mobile Model  
- Brand-wise performance  

### 3. Customer Analysis
- Customer Ratings distribution  
 
### 4. Payment Analysis
- Payment Method distribution  

---

## 🎯 Key Insights
- Identified top-performing cities in terms of sales  
- Found best-selling mobile models and brands  
- Analyzed customer satisfaction through ratings  
- Understood preferred payment methods  
- Observed sales trends over time (monthly & daily)

---

## 🚀 Conclusion
This project provides a clear understanding of mobile sales performance and customer behavior.  
It helps businesses make data-driven decisions to improve sales and customer satisfaction.
